# Zero to Quant

An interactive learning app that takes a learner from school arithmetic to quant-interview readiness, following `docs/curriculum.md`.

- `docs/design-research.md`: the researched design system (Brilliant's design language, recreated).
- `prototype/`: the approved Stage 1 clickable mockups.
- `docs/PLAN.md`: the Stage 2 engine blueprint (in progress).
