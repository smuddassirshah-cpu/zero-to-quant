- l11 (pot odds; tags `pot-odds`, `outs`, `implied-odds`). - l13 (a toy poker game; tags `bluff-frequency`, `defence-frequency`, `kuhn-poker`). - l14 (what information is worth; tags `value-of-information`, `perfect-information`, `imperfect-signal`). Method: the value of information is the expected payoff when you decide after seeing it, minus the expected payoff of the best decision now; it is never negative, never more than the value of perfect information, and zero when no message could change your decision.
