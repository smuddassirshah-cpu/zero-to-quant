## The `autograd.py` contract (binding on backprop level 4 and on every later course)

Later courses (`makemore`, `nn-train`, `cnn`, `sequence`, `representations`, `rl`, `gpt`, `interp`, `ml-int`) ship this file verbatim and rely on every name, signature and convention below. Change none of them without the main session's agreement.

- **The file.** One module, `autograd.py`, standard library plus NumPy only, UTF-8, well under 256 KB, no side effects at import beyond `import numpy as np`. Its first lines are a docstring naming it "backprop level 4 autograd" and `__version__ = "1.0"`. The canonical copy is `app/content/data/backprop/autograd.py`; the backprop level 4 author writes it (this one file outside the course folder is allowed for that level) and runs its own tests on it in the level's number script.
- **How later screens ship it.** On a Python `code` widget, `"files": { "autograd.py": "<the canonical file's exact text>" }` (AUTHORING section 3: `files` are written into the working directory, which is on `sys.path`, before the prelude), then `from autograd import Tensor, cross_entropy, softmax, sgd_step, grad_check, concat, unbroadcast`. Never paste an edited copy. Each level's number script that ships it asserts that every `files["autograd.py"]` string in the level's JSON equals the canonical file byte for byte (compare SHA-256), so a drifted copy fails the script. Within backprop level 4 itself the learner writes the class; the canonical file is the level's model solution, and l16's tests run against the learner's own code.
- **`class Tensor`.**
  - `Tensor(data)`: `data` is anything `np.asarray` accepts; stored as `self.data = np.asarray(data, dtype=np.float64)` (a copy is not promised); `self.grad = np.zeros_like(self.data)`; `self._prev` a tuple of parent tensors; `self._op` a short string; `self._backward` a no-argument callable. Properties `shape` and `T` (transpose of a 2-D tensor); method `item()` returns `float(self.data)` for a size-1 tensor.
  - Operators, each returning a new `Tensor`; a Python number or `ndarray` operand is wrapped as a constant `Tensor`; every binary op broadcasts as NumPy does and its backward sums the gradient back to each operand's shape with `unbroadcast`: `a + b`, `b + a`, `a - b`, `b - a`, `-a`, `a * b`, `b * a`, `a / b`, `b / a`, `a ** k` (`k` a Python number, never a tensor), `a @ b` (both 2-D; backward $G B^T$ and $A^T G$).
  - Methods, each returning a new `Tensor`: `sum(axis=None, keepdims=False)`, `mean(axis=None, keepdims=False)`, `tanh()`, `relu()` (gradient 0 at exactly 0), `exp()`, `log()`, `reshape(*shape)`, and indexing `a[idx]` with an integer array or a tuple of integer arrays (backward by `np.add.at`, so repeated indices add: the embedding lookup).
  - `backward()`: only on a tensor of size 1, else `ValueError`; sets its own `grad` to ones, builds the topological order **iteratively** (an explicit stack, never recursion: AUTHORING section 3 caps recursion at about 1,400 calls, and a sequence model's graph is deeper), then calls each `_backward` in reverse order. Gradients accumulate with `+=`; nothing zeroes them except `zero_grad()`.
  - `zero_grad()`: sets `self.grad` to zeros in place.
- **Functions.**
  - `unbroadcast(grad, shape) -> ndarray`: sums `grad` over the leading axes that broadcasting added and over every axis where `shape` has 1.
  - `cross_entropy(logits, targets) -> Tensor` (size 1): `logits` a 2-D tensor (n, K), `targets` a 1-D integer array or list of length n; the mean over rows of $-\log \operatorname{softmax}(z_i)_{y_i}$ in nats, computed with the row maximum subtracted (log-sum-exp); one fused backward, $(\operatorname{softmax}(z) - \text{onehot}(y))/n$.
  - `softmax(x, axis=-1) -> ndarray`: on a plain array, no gradient, max-subtracted; for sampling and reporting.
  - `concat(tensors, axis=0) -> Tensor`: joins tensors along an axis; backward splits the gradient.
  - `sgd_step(params, lr)`: `p.data -= lr * p.grad` for each tensor in `params` (in place, outside the graph); it does not zero the gradients.
  - `grad_check(f, params, h=1e-5) -> float`: `f` is a no-argument function that builds and returns a size-1 tensor from `params`; zero every gradient, run `f().backward()`, then for every entry of every parameter's `data` take the central difference $\tfrac{f(x + h) - f(x - h)}{2h}$ (restoring the entry), and return $\dfrac{\max |g_{\text{backprop}} - g_{\text{numeric}}|}{\max(\max |g_{\text{backprop}}|, \max |g_{\text{numeric}}|, 10^{-12})}$ over all entries of all parameters (the global relative error).
- **Conventions.** float64 everywhere: never cast to float32 (a tanh layer checks to 2.6e-11 in float64 and only 8.0e-5 in float32). Gradient checks use `h = 1e-5` and pass below `1e-6`. Integer indices and targets stay integer arrays (int32 in Pyodide's wasm is fine; never show a dtype in an answer). Parameters are tensors made by each course's own initialisation code from `np.random.default_rng(seed)`; the module holds no random state and no global graph. No op changes a tensor's `data` in place while its graph is in use, except `sgd_step`. Losses are averages over rows, not sums.
- **Reference sketch.** `docs/briefs/ai-s0s1-scripts/autograd_ref.py` is the brief writer's sketch of this contract, used only to check that it is coherent: on it every op passes `grad_check` below 1e-10, a 2,000-node chain runs `backward()` without recursion, and the level 3 course network gives loss 5.5568 at the start and 0.02502 after 200 steps at 0.05. Write the lessons and the canonical file yourself; use the sketch to test your file against, not as the file.
- **Growth.** A later course that needs another op (a convolution, layer normalisation, a masked softmax, `max`) writes it in a module of its own that imports `autograd` (for example `cnn_ops.py`, shipped the same way), with its own gradient check; it never edits `autograd.py`. A bug fix bumps `__version__` to "1.1", is recorded in `docs/reports/backprop-4.md` and `DECISIONS.md`, and every shipped copy is regenerated (the SHA check finds them).
