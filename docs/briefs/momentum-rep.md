```python
import numpy as np
def momentum_panel(n=500, T=300, seed=2, c=0.015, e=0.03, d=0.006, nf=4, fsd=0.035,
                   c_after=None, t_pub=300, crash=None):
    TMAX, L = 480, 36
    rng = np.random.default_rng(seed)
    size = rng.normal(0.0, 1.0, n)                 # log size as a z-score
    sig = 0.09 - 0.02 * np.tanh(size)              # small shares are noisier
    beta = rng.uniform(0.5, 1.5, n)
    lam = rng.standard_normal((n, nf))             # loadings on nf style factors
    s = rng.standard_normal((TMAX + L, n))[:T + L] * sig   # news shocks, 36 months burn-in
    m = (0.006 + 0.045 * rng.standard_normal(TMAX))[:T]    # market excess return
    F = (fsd * rng.standard_normal((TMAX, nf)))[:T]        # factor returns
    if crash is not None:                          # a bear market, then a rebound
        m[crash - 12:crash] = -0.03; F[crash - 12:crash, 0] = -0.03
        m[crash:crash + 3] = [0.12, 0.06, 0.04]; F[crash:crash + 3, 0] = [0.12, 0.06, 0.04]
    ct = np.full(T, c)
    if c_after is not None:
        ct[t_pub:] = c_after                       # the effect after publication
    cont = sum(s[L - k:L - k + T] for k in range(2, 13))   # lags 2 to 12: continuation
    rev = sum(s[L - k:L - k + T] for k in range(13, 37))   # lags 13 to 36: reversal
    idio = s[L:L + T] - e * s[L - 1:L - 1 + T] + ct[:, None] * cont - d * rev
    r = 0.004 + beta * m[:, None] + F @ lam.T + idio
    return r, size, m, F                           # r is (T, n) simple monthly returns
```

What it plants: each share's news shock moves its return by a further c = 1.5% of the shock in each of the next 2 to 12 months (under-reaction: momentum), by −e = −3% in the next month (one-month reversal, which is why the skip month helps), and by −d = −0.6% in each of months 13 to 36 (long-horizon reversal); market, four style factors and idiosyncratic noise make the long-short spread as noisy as a real one (monthly sd about 6%). Month 0 of the base panel stands for January 1965, so T = 300 is 1965 to 1989; the extension panel is `momentum_panel(T=480, c_after=0.005, t_pub=300, crash=420)` (1990 to 2004 appended, the continuation cut by two thirds, a crash planted at month 420); because every draw is made for 480 months and then cut, its first 300 months are exactly the base panel.
