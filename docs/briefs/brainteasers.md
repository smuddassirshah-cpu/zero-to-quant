**Engine limits to write around (every level).**
- A `derive` screen takes only an `expression`, `order` or `choice` widget.
- `expression` decides equivalence at six seeded points from 0.3 to 3 (whole numbers 1 to 12 with factorials or binomials), so a formula that differs only outside those points passes; prefer `numeric` for a single number and keep `expression` for a closed form such as $\tfrac{d(d+1)}{2}$.
- A `table` (canvas or widget) with 5 or more columns turns compact and scrolls sideways at 390 px: keep tables to 4 columns (transpose them: one row per pirate or per case).
- In `place`, one slot holds one chip, and a long KaTeX chip does not wrap at 390 px: keep chips short or use `order`.
- Set `shuffle: true` on every `choice` and `multi` except ordered options (counts in order, steps).
- `longform` is accepted only in homework and exams: the validator refuses it in a review (`longform items belong in homework and exams`), although AUTHORING section 5 mentions reviews.
- A `manipulate` target must be reachable from its start (the validator runs the solver); dead ends are ops with a `why`, or `reject: true` with a `why`.
- Grid cell text is plain text (no KaTeX; use `½`, `−`, `²`); grid ids are one-based (`r1c1`), table ids zero-based (`r0c0`).
- A `pair` stacks two canvases below 480 px; there is no triple canvas.
