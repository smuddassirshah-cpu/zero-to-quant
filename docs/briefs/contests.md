A pattern to copy, adapted from `graphs-dp` l7:

```python
class _Counted(list):
    reads = 0
    def __getitem__(self, i):
        _Counted.reads += 1
        return list.__getitem__(self, i)
    def __iter__(self):
        _Counted.reads += len(self)
        return list.__iter__(self)

def reads_for(fn, xs):
    _Counted.reads = 0
    fn(_Counted(xs))
    return _Counted.reads
```
