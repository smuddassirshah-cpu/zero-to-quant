# Level briefs

One file per course, `docs/briefs/<course>.md`, with a `## Level <n>` section per level. A brief-writer agent writes the file from `course.json`, `curriculum.md` and the completed neighbouring courses; a level agent then authors one level from its section. `EXAMPLE.md` is a brief in the agreed form (the arma level 1 brief).

Each level section gives, in this order: context (what the learner has met, which earlier lessons to read for voice and shared numbers, the reference text); the runtime facts that matter (packages, load times, seeds, what the runtime cannot do); the canvases to use; one paragraph per lesson (hook, explore, ladder, trap, edge case, generalise, transfer, and the named `code` screens with their function signatures and what the tests check); the number-checking rule; the homework requirements (two `code` items with one at difficulty 5, an `order` item, a `longform` with a 10-point rubric); the scratchpad folder; the do-not-edit rule.
