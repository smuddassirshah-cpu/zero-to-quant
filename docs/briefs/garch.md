The course data set (use it everywhere unless a lesson needs another; describe it in prose as "2,000 days of a simulated share's daily returns, from a GARCH(1,1) whose parameters we know"):

```python
def simulate_garch(omega, alpha, beta, n, seed):
    """GARCH(1,1) returns: r_t = sigma_t z_t, z_t ~ N(0, 1),
    sigma2_t = omega + alpha r_{t-1}^2 + beta sigma2_{t-1}, started at the long-run variance."""
    z = np.random.default_rng(seed).standard_normal(n)
    r = np.empty(n); s2 = np.empty(n)
    s2[0] = omega / (1 - alpha - beta)
    for t in range(n):
        if t > 0:
            s2[t] = omega + alpha * r[t - 1] ** 2 + beta * s2[t - 1]
        r[t] = np.sqrt(s2[t]) * z[t]
    return r, s2
```

True parameters: ω = 0.000002, α = 0.08, β = 0.90, 2,000 days, seed 7: `r, s2 = simulate_garch(2e-6, 0.08, 0.90, 2000, 7)`. Persistence α + β = 0.98; long-run variance ω/(1 − α − β) = 0.0001, so a long-run daily sd of exactly 1% and an annual volatility of √252 × 1% = 15.87%; the half-life of a variance shock is ln 0.5 / ln 0.98 = 34.31 days. The hand fit (the reference implementation every level uses; returns in percent, so ω is about 0.02 rather than 0.000002 and the optimiser sees parameters of similar size; this is what the `arch` package does by default and the lesson should say so in one sentence):

```python
import numpy as np
from scipy.optimize import minimize

def garch_variance(params, r):
    """Conditional variances for returns r (in %): sigma2_0 is the sample variance of r."""
    omega, alpha, beta = params
    s2 = np.empty(len(r)); s2[0] = r.var()
    for t in range(1, len(r)):
        s2[t] = omega + alpha * r[t - 1] ** 2 + beta * s2[t - 1]
    return s2

def neg_loglik(params, r):
    """Minus the Gaussian log-likelihood, zero mean: 0.5 * sum(ln 2pi + ln s2 + r^2 / s2)."""
    s2 = garch_variance(params, r)
    return 0.5 * np.sum(np.log(2 * np.pi) + np.log(s2) + r ** 2 / s2)

def fit_garch(r):
    return minimize(neg_loglik, x0=np.array([0.05, 0.05, 0.90]), args=(r,), method="SLSQP",
                    bounds=[(1e-6, 10.0), (0.0, 1.0), (0.0, 1.0)],
                    constraints=[{"type": "ineq", "fun": lambda p: 0.9999 - p[1] - p[2]}],
                    options={"ftol": 1e-10, "maxiter": 500})
```

Constraints are by bounds (ω > 0, α ≥ 0, β ≥ 0) plus one inequality (α + β below 1, so the variance is stationary); the starting point (0.05, 0.05, 0.90) is fixed; the mean is taken as zero (the simulated returns have mean zero; for real returns subtract the sample mean first and say so). On `rp = 100 * r` for the course data set, `fit_garch(rp)` converges in 15 iterations to ω̂ = 0.0121 (%², true 0.02), α̂ = 0.0629 (true 0.08), β̂ = 0.9235 (true 0.90), minus log-likelihood 2623.8302 (2625.3778 at the true parameters, 2657.1722 at the starting point); persistence 0.9864; long-run variance 0.8885 %², a daily sd of 0.9426% and an annual volatility of 14.96%; half-life ln 0.5 / ln 0.9864 = 50.62 days. Pyodide 0.27.7 (SciPy 1.14.1) and CPython (SciPy 1.18.1) agree to all four places shown, and the fit takes 0.19 s in Pyodide. The fitted values are near the true ones, not equal (2,000 days give standard errors of roughly 0.015 for α and 0.02 for β; say so whenever a fit is shown). Test tolerances: a learner's `neg_loglik` and `garch_variance` are deterministic, so test them exactly (`isclose`, rel 1e-9) at given parameters; a learner's fit may use a different optimiser path, so test fitted parameters rounded to 3 places with `math.isclose(..., abs_tol=0.003)` against the reference values above, plus interval checks against the truth (0.03 < α̂ < 0.13, 0.85 < β̂ < 0.96, 0.95 < α̂ + β̂ < 0.9999); never test a fitted parameter beyond 3 places. On only the first 1,000 days the same fit gives (0.0430, 0.0602, 0.8663), persistence 0.9265 and a long-run daily sd of 0.765%: a short sample fits badly, which is l7's edge case and the reason level 3 fits on all 2,000 days.
