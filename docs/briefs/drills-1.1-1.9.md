# Brief: topic 1.1 and 1.9 drills (packs `py`, 30 drills, and `cpp`, 25 drills; PLAN 2d item D; gap file rows 1.1 and 1.9)

Topics 1.1 (Python) and 1.9 (C++) teach by guided lessons and have almost no independent practice: small programs written from a blank function. Everything in `docs/briefs/drills-1.8.md` holds (fields, tests, fresh rule, checks) with the additions of `docs/briefs/drills-ci-packs.md` on `planted` (two or three per drill, `planted-check --require`) and on `notes`, except where this brief differs. Read `docs/reviews/review-drills-ci-1-2.md` and `review-drills-ci-3-4.md` first: the faults found there (a brief whose worked answer disagrees with its tests, an unplanted wrong solution passing every test, sample data recalled from a coding site, an index row disagreeing with its file) are the ones your own check must rule out.

## Differences

- These are not algorithm puzzles. Each is a small program a working quant developer writes in a day: parse, clean, compute, format. One idea each, from one named lesson's material, used without the lesson's scaffolding. Never a lesson's own task under a new story.
- `difficulty` 1 to 3 per ten drills: three at 1, four at 2, three at 3 (for the 25: eight, ten, seven). `pace` 300 to 1,200 seconds. No `pattern` unless one in the fixed vocabulary truly fits; put the idea in `tags`.
- `course` is the taught course; `skills` are skills its lessons declare; the drill uses only what the course has taught by the lesson named in the report.
- Large-input tests only where the lesson teaches cost (vectorising, reserving, passing by reference). Otherwise tests are about correctness: empty input, one element, ties, negatives, bad rows, floating-point comparison with the tolerance stated in the brief.
- Pack `py` (`py-<slug>`, Python): `py-found` 12 (strings and formatting, lists and dicts, comprehensions, functions and defaults, exceptions, classes, files and parsing), `numpy-pandas` 12 (array arithmetic and broadcasting, boolean masks, axis reductions, rolling and shift, groupby, merge, resample, missing data), `plotting` 6 (functions that return the data a chart needs: bins and counts, cumulative returns, drawdown series, a tidy table for a grouped bar; tests check values, never pixels). Two agents: A `py-found` and `plotting` (18), B `numpy-pandas` (12). Existing untagged drills in these courses are listed in `drills/index.json`: do not repeat them.
- Pack `cpp` (`cpp-<slug>`, C++, read AUTHORING section 3 on the C++ runner first: no exceptions, `-O1`, the result types tests can compare): `cpp` 17 (references and const, `std::vector` and `std::string`, structs and classes with invariants, RAII, templates, `std::map` and algorithms, iterators, move), `cpp-pricing` 8 (a payoff class hierarchy, a discount curve lookup, a binomial step, a running statistics accumulator, a fixed-point money type). One agent. Planted solutions in C++ should include the classic slips: integer division, an off-by-one on `size()`, a copy where a reference was needed that loses the update, uninitialised accumulators.
