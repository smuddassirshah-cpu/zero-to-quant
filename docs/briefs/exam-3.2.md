## 4. Keys and wrong answers, each computed twice

Every number was computed by two routes. Route A is a closed form; route B is independent: a quadrature, a linear solve, a grid Markov chain, an exact `Fraction`, SymPy or a seeded simulation. Scripts, which assert that the routes agree, are in `docs/briefs/exam-3.2-scripts/` (`check_ito.py`, `check_mp.py`, `check_pdes.py`, then `check_fix.py`, which supersedes the I6 rounding, I10 part b, I11 and P1 sections of the first three). Run with `PYTHONPATH=<folder with scipy, sympy, numpy>`; the sandbox needs `pip install --target <folder> scipy sympy`. The author re-runs them, copies them to the report's script folder and extends them to every number the final prose states (including each `tol` and any intermediate value an `explain` quotes).

Tolerance, unless stated: absolute 0.0005 on a 4-place answer, 0.01 where the item says "to 2 places". The key is the number; "slip" lines are the two `wrong` values and the `byKey` text they need.
