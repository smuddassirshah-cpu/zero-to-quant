## Departures from the brief

- **l17 hook numbers changed.** The brief's example (calm 0.1 and sd 1, volatile −0.4 and sd 3, in £k; variance 2.64 against the naive 2.6) is correct but cannot be shown by a simulation. The sample variance of 5,000 draws has a standard error of 0.0486, larger than the 0.04 gap (it reaches 0.0109 only at 100,000 draws). The hook now uses lesson 16's regime (calm 80%, £120, sd £100; volatile 20%, −£180, sd £300): naive 26,000, true 40,400, standard error 1,195 at 5,000 draws, so the gap is 12 standard errors. The brief's numbers stay as the l17 edge-case screen (screen 9: $2.6 + 0.04 = 2.64$).
- **l17 mean.** The brief says the overall mean is 0 "(l16)". Lesson 16's regime gives £60 ($0.8 \times 120 - 0.2 \times 180$), and the new hook uses £60. The brief's 0.1 and −0.4 do average to 0 ($0.08 - 0.08$), which is true of the edge example.
- **l18 simulation margin.** The brief's second term is 500 on 18,500 (2.7%). At 20,000 simulated days the standard error of the sample variance is 187, so the gap is 2.7 standard errors. The curve is seeded (seed 8, final value 18,508) and the screen asks only "above the dashed line", with the exact 18,500 added in the explanation. The gap would be unsafe to show at a smaller sample.
- **l18 count distribution.** "Mean 20 and variance 20" is given as 15, 20 or 25 with chances 0.4, 0.2 and 0.4, so no Poisson is needed. Fills are £35 or −£25 with equal chance (mean £5, sd £30).
- **l20 geometric variance.** The brief takes $\mathrm{Var}(T) = 3(0.6)/0.4^2$ from lessons not yet met: limits-thm l2 teaches the geometric variance, after this course. Screen 7 derives it from l17's law (one wait: $V = 0.6V + 1.5$, so $V = 3.75$).
- **l20 stages.** The stage counts (252, then 10) share one table screen with the probability, and the correlation $-0.65$ is in the trap's explanation and the homework instead of its own ladder screen, to stay within 12 screens.
- **l18 insurer.** The brief's insurer is in the quiz (as a standard deviation, £13,115), not a ladder screen.
- **Code screens.** l18 gives `random_sum` in the starter and asks the learner for the exact moments; a seeded simulation by the learner would need the same draw order as the reference. The homework code item fixes the draw order in comments for the same reason.

## Seeds and conventions

- `series` simulations (`sim.running: "varp"`): l17 seed 1, 5,000 days; l18 seed 8, 20,000 days with `let` binding $N$ (`pick([15, 15, 20, 25, 25])`). Seeds were chosen by running the engine's own `sim.js` under Node (`simlib.mjs`) over seeds 1 to 16.
- Python in the code screens: `random.Random(seed)`, standard library only (`random`, `fractions`, `math`). l18 uses seed 8; the homework uses seeds 1, 3, 4 and 7.
- Money is £ throughout; $\mathrm{Var}$ and $\mathrm{Cov}$ use `\mathrm`.
- The two regime examples of lesson 16 are reused: £120 and −£180 at 80/20 (l17, l18's doubling transfer, the review and the homework), with the brief's £k example kept in l17's edge screen.
- The die and coins is the exam's `e-die-coins` set-up (l17 and l18), the market and stock table is lesson 15's.
