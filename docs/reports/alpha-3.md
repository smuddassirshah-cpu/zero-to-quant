Every lesson has a hook, an interactive explore (series `revealAt` slider, or a draggable point on a plane), a named term, a ladder with code screens, a trap, a generalise or derive screen, a transfer, a summary and a quiz. Traps: overlapping daily dates (l9), a rising IC read as a stronger signal (l10), whole-sample quintile cut points (l11), weights scored on the data that chose them (l12). Edge cases: thin and constant-signal dates (l9 code tests and quiz), horizon 0 and a horizon longer than the data (l10 code tests and quiz), ties at a cut point and thin dates (l11), perfectly correlated signals and a negative weight (l12 quiz).

## Prelude and conventions

- Every code screen's hidden `prelude` holds `import numpy as np` and `import pandas as pd` on separate lines (the import-scan issue level 1 raised), the brief's `make_panel` verbatim, and `forward_returns`, `momentum_12_1`, `reversal_5d` and `cs_zscore` copied at generation time from the `solution` of level 1's l4 and level 2's l5 to l7 (exact text, imports removed), then the level 3 functions written on earlier screens.
- Small panels in tests: `make_panel(30, 300, 5)` (`p`, `ret`, `rev`, `fwd5`), `make_panel(30, 400, 5)` (l10: `ret4`, `rev4`, `fwd4`), `make_panel(40, 400, 7)` (homework). Short-window momentum on the small panel: `momentum_12_1(ret, 60, 5, 40)`, using level 2's keyword arguments. Full panel `make_panel()` (seed 2310) only inside cached helpers: `momentum_ics()` (l9 `ic_summary`, budget 20 s) and `daily_momentum_ics()` (homework Newey-West, budget 25 s).
- Rank IC: Pearson correlation of average ranks per date (`corrwith(axis=1)`), shares with both values only, dates with fewer than `min_shares = 10` dropped; constant-signal dates give NaN and are dropped. Matches a per-date Spearman reference and `scipy.stats.spearmanr` to 5.6e-17.
- Dates: monthly study on rows `252, 273, ..., 1236` (47 dates, as the brief's check); horizon studies on dates `max(step, h)` rows apart from row 0; weekly combination on rows `220, 225, ..., 1250` (207 dates, the rows on which momentum exists, on the same grid as l10's 5-day IC); research split 3 January 2022.
- Quantile buckets: $\lceil q\,r/n \rceil$ on average ranks (ties share a bucket), dates with fewer than $q$ shares skipped, cut points per date.
- `spread_stats` monotone flag: every step of the bucket means strictly positive.
- Newey-West: Bartlett weights $1 - k/(L+1)$, autocovariances divided by $n$; equals statsmodels' OLS HAC t with `use_correction=False` exactly (checked at lags 0, 1, 4, 10).
