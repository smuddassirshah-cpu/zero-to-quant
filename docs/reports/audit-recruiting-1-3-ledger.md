# Claim ledger: recruiting, levels 1 to 3

Concept audit ledger for `app/content/courses/recruiting/` (l1 to l15, review-1 to review-3, homework-1 to homework-3). Stage 0 depth: definitions, rules, "always / never / every / only" claims, conventions, named-firm and numeric claims, and every graded key, wrong option and slip. Findings are in `docs/reviews/audit-recruiting-1-3.md`.

Rows: 1077. Verdicts: correct 1022, wrong 1, imprecise 20, misleading 1, unverified 33.

Basis shorthand: "L1 script" is `docs/reports/recruiting-L1-concepts.py` (L2, L3 likewise). "Reported" rows are third-party or dated firm facts that the content labels as reported; they are `unverified`, never a pass, because no source could be reached from the audit sandbox. Each names what would settle it.
