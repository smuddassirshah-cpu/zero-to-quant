Second blind audit of `app/content/courses/numerics/` levels 1 to 3 (l1 to l12, review-1 to review-3, homework-1 to homework-3). One row per definition, result, method step, convention, always/never/every/only claim, code-behaviour claim and the reasoning of each explain, why, hint and feedback line (lines that restate the same reasoning share a row). Paths are JSON paths inside the file. Verdicts: `correct`, `wrong`, `imprecise`, `misleading`, `unverified`. 244 rows: correct 229, imprecise 10, wrong 3, misleading 2, unverified 0.

`sim Ln:name` is a check in `docs/reports/numerics-Ln-concepts-r2.py`. Every code task's solution was run against its hidden tests, and its starter was checked to fail them, in those scripts.
