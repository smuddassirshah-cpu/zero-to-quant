Blind concept audit (brief: `docs/briefs/concept-audit.md`) of `app/content/courses/numerics/` levels 1 to 3: l1 to l12, review-1 to review-3, homework-1 to homework-3. Claim ledger: `docs/reports/audit-numerics-1-3-ledger.md` (232 rows: correct 199, imprecise 22, wrong 10, misleading 1, unverified 0; several rows can belong to one finding). Checks: `docs/reports/numerics-L1-concepts.py`, `-L2-concepts.py`, `-L3-concepts.py`. Arithmetic is left to the author's number scripts; this audit covers meaning: definitions, theorems and their hypotheses, conventions, always/never claims, what Python and NumPy do (run), graded keys under the stated convention, `wrong[]` options under alternative methods, the reasoning in explain, why, hint and feedback lines, and whether the code teaches the method the text claims.

Findings are `N. file | JSON path | severity | problem | evidence and basis | exact fix`. Severities: `wrong`, `imprecise`, `misleading`. Each is also tagged `serious` (a learner would carry away a wrong definition, theorem, method, convention or graded answer, or code that teaches a wrong method) or `minor` (wording or precision that changes no understanding). There are 22 findings: 5 `wrong` (4 serious, 1 minor), 16 `imprecise` (3 serious, 13 minor), 1 `misleading` (minor). Serious: 7 (findings 6, 7, 10, 11, 12, 15, 18). No numeric key is wrong. Two keyed option texts carry a false clause (findings 18 and 22) and one rubric line awards marks for a false statement (finding 6). No `wrong[]` option or slip value is correct under a valid alternative method.

Every fix below is paste-ready text for the named path. Where a path holds several sentences, only the sentence named is replaced and the others stay.
