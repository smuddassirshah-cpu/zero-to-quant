Independence is assumed where it is stated ("fair coin", "one day's move told you nothing about the next"); dependence is taught where it exists (cards without replacement, unknown coin, mean-reverting spread). Expected false discoveries use linearity, so the dependence between strategies tested on one price history does not affect the keyed counts.

Each split in the lesson is by a variable fixed before the choice, so each keyed conclusion is right. review-5 `r-model-error` "must be true": a reversal forces both models to have the same harder group (if they disagreed, A overall ≤ A's worse rate < B's better rate ≤ B overall), and then A must weight it more.
- Survivorship. All averages and the gap formula are right; random closure is unbiased (Monte Carlo 2.385 against 2.4); the index backtest contrasts original members with today's members correctly.
- Trading signal.
