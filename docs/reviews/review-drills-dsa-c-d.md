# Drills pack `dsa`, sub-packs C and D and three rewrites: second-reader findings

Scope: the 30 drills of sub-packs C (trees, heaps and tries, intervals) and D (graphs, dp, greedy, backtracking) in `app/content/drills/dsa-*.json`, as listed in `docs/reports/drills-dsa-c.md` and `-d.md`, plus the three B drills rewritten by the A/B fix pass without a read: `dsa-oncall-rota`, `dsa-depth-block`, `dsa-range-volumes`. Checked against `docs/briefs/drills-1.8.md`, AUTHORING section 5 "Drill" and "Exam freshness", and the review `docs/reviews/review-drills-dsa-a-b.md`.
Method: I wrote my own solution to every drill from its `brief`, `constraints` and examples only, before reading the model `solution`, and ran it on every example and hidden test (`mine_c.py`, `mine_d.py`, `mine_b3.py`). For each drill I planted at least three wrong solutions: an off-by-one or boundary slip, a tie, order or greedy slip, and the slow method the constraints name (`wrong_c.py`, `wrong_d.py`; each test gets a 2 s native alarm, about 4 s in Pyodide, and a run stops at its first timeout). Where a planted solution passed every test I checked by brute force whether it is really wrong (labels starting `V` are valid variants, not faults). `extra_checks.py` holds the brute forces behind each claim below and computes every proposed new test with the model and with my solution. `fresh_grep.py` greps the `ds`, `algo-think`, `graphs-dp`, `coding-int` and `contests` folders and the other drills for each task; `meta_checks.py` checks voice marks, spelling, `index.json` rows, skills, the difficulty mix and the time-limit sentence.
Scripts: `docs/reviews/drills-dsa-c-d-scripts/` (run from the repo root with the scratchpad venv Python: `harness.py mine <mine_x.py> app/content/drills <ids>`, `harness.py model app/content/drills`, `harness.py wrong <wrong_x.py> app/content/drills <ids>` in groups of about eight ids, `extra_checks.py app/content/drills`, `fresh_grep.py app/content`, `meta_checks.py app/content`). Every script finishes in under 25 s.
Format: `N. file | JSON path | severity | what is wrong | exact fix`. Severity: error = wrong test, wrong example or a statement that teaches something false; warning = ambiguity, a test gap or a repeated lesson task; note = otherwise.

## Tool results

- My own solutions: 33 of 33 drills pass every example and hidden test (C 15, D 15, rewrites 3). No `expect` and no worked example is wrong. Every model solution passes and every starter fails at least 7 tests.
- Planted solutions: 112 run, four of them valid variants. Off-by-one, tie and greedy slips caught in 30 of 33 drills; not caught in `dsa-kiosk-change` (finding 4), `dsa-print-queue` (6) and `dsa-lift-buttons` (7). The slow method the constraints name is caught in 31 of 33; not caught in `dsa-loop-depots` (8) and `dsa-swapped-levels` (9). `dsa-shift-pay`'s planted "states start at 0" passes because it is correct (finding 1).
- Valid variants that pass and are right, so no finding: `dsa-double-booked` sorted by end (the mirror of sorting by start), a "best only at the first visit of each start" form of `dsa-window-every-venue` (equal to brute force on 20,000 random feeds), the up-if-below greedy for `dsa-lift-buttons` (equal to BFS on every input with `n` up to 12), and `dsa-server-loads` with the bound `>` in place of `>=`.
- Brute-force cross-checks in `extra_checks.py`, all agreeing with the models: `window-every-venue` (3,000 random feed sets, ties included), `swapped-levels` (3,000 random swapped trees), `loop-depots` (4,000 loops; the restart rule does land on the smallest working depot, so notes[1] is true), `kiosk-change` (3,000 queues against every change choice), `server-loads` (400 cases against every assignment), `shift-pay` (660 cases against every working-day set), `footpath-slabs` (exhaustive tilings for `n` up to 10).
- `docs/reports/drills-dsa-c-check.py`: exit 0, `errors: 0`. `docs/reports/drills-dsa-d-check.py`: exit 0, `15 drills, 0 errors`. `docs/reports/drills-dsa-b-check.py` (covers the three rewrites): exit 0, `15 drills, 0 errors`. Independence judged in finding 21.
- Voice: `voice-scan.py 35` on a copy of the 33 files: 948 sentences, 0 over 35 words, 0 explanations over three sentences. No exclamation marks, em-dashes or en-dashes in prose; no American spellings found.
- `index.json` rows match `name`, `course` and `difficulty` for all 33; every `skills` entry is declared by a lesson of the drill's `course`; `how` gives the right test count everywhere. Difficulty mix 5 / 6 / 4 in C and in D; three `stdin` drills in each.
- The drill page arms one 5 s timer for the whole run (`app/js/screens/drill.js` line 332, `LIMIT_MS = 5000` in `exec`), so "All the tests in a run share one 5-second limit in the browser." is the true sentence. Only the three rewrites carry it (findings 3 and 12).
- I did not run the validator or the playthrough (both write files, and this pass only reads); the authors report both green.
