## The kind of backtest L4 (asked)

The objective is l16's "Write a one-page results note, including what failed." Read by its letter the verb rule gives `code`, but a test cannot grade the note's judgement ("what failed"), and a `code` note generator would repeat l16 screen 10's `results_note`. `data` is for a task read from a data file; this one gives a seven-row results table and four log lines, and asks for no computation from raw data, so moving the table into `content/data/` would only relabel it. The product is written prose whose graded content is worked figures (drag, standard errors, the no-edge bar, impact, capacity), self-marked against a rubric. That is the `derivation` shape under section 5's "written maths" clause, and grading is identical to a longform `data` task. **Verdict: keep `derivation`.** The report's reason (a data file would sit outside the folder) is a process obstacle, not a reason for the kind (BT4-3). The main session may want one DECISIONS line: "write" with a prose product takes `derivation`.
