# Counting levels 1 to 3 (Counting; Harder counting; Vectors): second-reader findings

Scope: `app/content/courses/counting/` l1 to l13, `review-1` to `review-3` and `homework-1` to `homework-3` (19 files). This is a Stage 0 course for a GCSE-entry learner, so I also checked each step against what the course and its `requires` have taught, and every convention against UK GCSE and A level usage. Continuity skim of the courses that require these levels (`counting-chance` L1, `vectors` L1 to L3, `series` L3, `proof` L2, `multivar` L2) and of every cross-reference. No `docs/briefs/counting.md` and no `docs/reports/counting-*.md` exist (the course predates the brief system), so the levels were read against `docs/AUTHORING.md` and the course map.

Method: I read every screen, quiz item, review and homework item in full. I recomputed every graded key, every `wrong[]` value and every number in prose, hints, `why`s and feedback in three new scripts. Each count is found twice: once by brute-force enumeration with `itertools` and once by the lesson's formula. The scripts enumerate distinct permutations, R/U route words checked cell by cell against the grid canvases, seatings in a row and round a table, dice, PINs, 2-card and 5-card hands, and weak orders for ties. Vectors are computed by components and again by `hypot`/`atan2` or the cosine rule. Canvas data (grids, trees, Venn values, vector arrows) is read from the JSON and checked against the text. I read every `byKey` line against the widget key it fires on. `tap-regions` returns the first wrongly tapped id, else the first missing one (`tap-regions.js` line 82). `order` returns the line at the first misplaced position (`order.js` line 199). I graded the three `expression` keys with the app's own `exprEqual` (`grade.js`) and Compute Engine 0.30.2 from the local CDN, using forms a learner would type and the listed slips. The scratch harness is `<scratchpad>/read-counting-1-3/expr-check.mjs`. The numbers in every proposed fix were checked by brute force in `<scratchpad>/read-counting-1-3/proposed.py`. There are no code items in these levels.
