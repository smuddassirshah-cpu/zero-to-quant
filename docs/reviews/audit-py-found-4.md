## Runtime and version notes

The learner runtime is Pyodide 0.27.7. I ran it in node from the local packages: CPython 3.12.7, pytest 8.1.1, `sys.argv == ['']`, `__name__ == '__main__'`.

- `statistics.stdev([0.012])` raises `StatisticsError: stdev requires at least two data points` in Pyodide, as l15 screens[4] says. The wording dates from Python 3.11; older versions say `variance requires`. Correct for the runtime.
- `sum([0.01, -0.02, 0.015, 0.005, -0.01])` is `-8.673617379884035e-19` in Pyodide, as l15 quiz[2] says. From Python 3.12 `sum` is compensated, so older versions give a different speck. The key holds either way: the plain left-to-right sum is also off zero.
- `assert` does nothing under `python -O` (Language Reference 7.3). Pyodide does not run that way, so l15's rule holds for learners. No finding.
- Finance conventions: returns are simple returns, given by formula and never named; no log returns appear. A return is dated at the later close (stated in `h4-worst-days`). The first close has no return, so $n$ closes give $n - 1$ returns. Functions return decimals and format with `%`. Total return is last over first, and summing is called an approximation. Volatility uses $n - 1$ and $\sqrt{252}$, or $\sqrt{52}$ for weekly data. No calculation looks ahead. All money is in £.
