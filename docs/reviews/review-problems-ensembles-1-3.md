# Problem sets 2.1, ensembles levels 1 to 3: second-reader findings

Scope: `app/content/courses/ensembles/problems-1.json`, `-2`, `-3`: 12 problems, 57 parts (54 numeric, 3 choice), 162 `wrong` entries. Rules: `docs/briefs/chained.md`, the Author rules of `docs/briefs/chained-prompts.md`. Pattern: `review-problems-analysis-1-3.md`.

Method. The author's script was run first. Lessons l1 to l12, `review-1` to `-3` and `homework-1` to `-3` were dumped to learner-facing text (canvas data left out) and searched for each problem's numbers, data sets, nouns and sentences; the stories were searched across `app/content/`. Every part was solved by hand from its text, then again in `docs/reports/problems-ensembles-numbers-read.py`, which imports nothing from the author's script and types every data set from the prose. Route 1 is exact: fractions, and a brute search over every midpoint split (each "best split" is shown best, each tie shown a tie). Route 2 is another method: scikit-learn's own trees, pruning path, `feature_importances_`, `oob_score_`, `TimeSeriesSplit`, `GradientBoostingRegressor` and `GradientBoostingClassifier` stage by stage; a 60,000-forest bootstrap simulation; the variance of an average from the full covariance matrix; statsmodels' z test; a NumPy position ledger. Every `wrong` value was rebuilt from the slip its line names, each band was tested against the key band and its neighbours, and the numbers printed in feedback and `explain` strings were recomputed. Claims were read against the lessons: weakest-link order, class-boundary splits, the class-0 rule for uncovered rows, $\lfloor\sqrt{p}\rfloor$, the Newton leaf, label overlap, depth as interaction order. No browser was run.

Tags: `wrong`, `misleading`, `reuse`, `voice`, `continuity`, as the Reader brief lists them.
