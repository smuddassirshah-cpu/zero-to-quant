**analysis L4: N = 1330 and the ε-N steps.** $E = \{x : |x| \ge \tfrac12\}$, and $h_n$ falls in $|x|$ ($h_n'(x) = -2nx/(1+nx^2)^2$), so $\sup_E h_n = h_n(\pm\tfrac12) = \tfrac{4}{n+4}$ (sympy, and a float grid on $[0.5, 20.5]$). Every ε-N step holds. In (a) one $N$ is fixed before $\delta$, by the $\tfrac\varepsilon3$ split; the moving point uses $N = \max(N_1, N_2)$ with uniform convergence applied at $x_n \in D$. In (b), $0 < h_n(x) < \tfrac{1}{nx^2}$ and $N > \tfrac{1}{\varepsilon x^2}$, checked at sample points. In (c), $N > \tfrac4\varepsilon$ gives $\tfrac{4}{n+4} < \tfrac4n \le \tfrac4N < \varepsilon$. $h_n(\tfrac{1}{\sqrt n}) = \tfrac12$ exactly, so $\varepsilon = \tfrac12$ has no $N$, because the inequality is strict. Hypotheses are exact: $a \in D$, each $f_n$ continuous at $a$, uniform convergence on $D$. `rubric-passes.mjs`: two passing sets; the minimal pass is rows 1 to 4 (9 points), and only row 5, the part the prompt marks "Optional, one more point:", can be left out.
