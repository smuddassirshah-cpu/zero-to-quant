# Topic 1.9 (C++): second-reader findings

Scope: every lesson, review and homework file in `cpp` (18 lessons, 4 reviews, 4 homeworks) and `cpp-pricing` (12 lessons, 3 reviews, 3 homeworks), with both `course.json` files. There is no topic exam yet; the last section proposes one.
Method: every stated number recomputed (Python for maths, CRR trees and Black-Scholes; the app's own clang 21 / libc++ WebAssembly build for every C++ figure, through the Node replica of `app/js/screens/cpp-worker.js` and `app/js/engine/widgets/cpp-grade.js`). Every C++ `code` widget's solution was compiled and run against its hidden tests, and every starter checked to fail (`check.mjs`). A mutation pass planted simple wrong versions of every solution (operator swaps, dropped guards) and listed the ones that still pass every test (`mutate.mjs`). g++ 13.3, clang 18, AddressSanitizer and LeakSanitizer transcripts were rebuilt on Linux and compared with the consoles. Distractor values were re-derived from their `why`; tolerance overlaps scanned (`tolcheck.py`); style scanned (`style2.py`, `sentcount.py`). Scripts and logs are in the scratchpad folder `review-1.9`.
Format: `path | screen/item | severity | what is wrong | fix`. Severity: error = wrong number, false claim or wrong grading; warning = weak explanation, teaching or test gap; note = style or transcript detail.
