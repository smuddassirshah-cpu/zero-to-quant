## How each claim was checked

Every C++ claim was compiled and run with the page's own code path: `Z.cppCode.lib.unit` of `js/engine/widgets/cpp-grade.js` builds the translation unit, and the `FLAGS`, `LINK`, `RUNTIME` and `runOne` of `js/screens/cpp-worker.js` compile and run it. The compiler is YoWASP clang 21.1.4 from the local CDN, in node WASI: wasm32, `-std=c++17 -O1`, libc++ hardening (extensive), no exception support. The node port is the round 1 auditor's harness file, reused as tooling only (I read no findings from that folder); it reproduces the page on all 28 solutions, examples and starters.

- 28 code widgets: every solution passes its hidden tests and its examples, and every starter fails.
- 165 natural codings (wrong ones, and valid alternatives) were submitted to sweep every `feedback.byKey.test-N` line and to see whether hidden tests reject the obvious wrong programs. Of the 58 `test-N` lines, 45 are reached first by at least one submitted coding of the slip they name (the two lines of finding 2 only in part); the other 13 only describe their test, and each description is true. Of the 12 `compile` lines, the three that name a message (`l15` screen 5, `l17` screens 4 and 5) are reached with that message; the other nine are generic. The three `error` lines (`l14` screens 3 and 6, `l18` screen 5) cannot be shown, as round 1 put in the inbox: a stopped program gives `test-N`.
- 34 claim programs: sizes on wasm32, capacity growth, copy and move counts, the special-member table, `noexcept` and reallocation (including a move-only type), what the undefined snippets do in this app, the compiler output of the vanished null test.
- 91 pure Python checks recompute every stated figure.

Undefined behaviour is never stated as a definite outcome in these levels: each such screen says "in this app's run", "typically" or "undefined", and the app-specific outcomes it reports are the ones I measured (erase loop, `transform` into an empty vector, `max_element` on an empty range, the null read, the `<=` comparator).
