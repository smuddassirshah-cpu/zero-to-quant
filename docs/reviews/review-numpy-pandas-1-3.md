## Version notes (Pyodide 0.27.7: NumPy 2.0.2, pandas 2.2.3)

- l8 `screens[4]`: `df[mask]["flag"] = -1` raises `SettingWithCopyWarning` in pandas 2.2.3 and leaves `df` unchanged, as the screen says. Under pandas 3 (copy-on-write) `df` is still unchanged but the warning is `ChainedAssignmentError`, so `explain.text` and `feedback.byKey.error` (and the key, until finding 16 lands) would then name the wrong warning. The L2 script checks this as VERSION and skips it under pandas 3.
- `resample("ME")` (l11, review-3, homework-3, l11 `generalise`) needs pandas 2.2 or later; pandas 2.2.3 has it, and older pandas would raise.
- `pct_change` on a Series with gaps: pandas 2.2.3 forward-fills them first with a `FutureWarning`, pandas 3 does not. No graded item depends on it. Every solution fills or drops gaps before `pct_change` (all 45 pass on both stacks with no warning), and the text only says an empty month "needs a decision" (review-3 `items[9]`, l11 `screens[5]`).
- Pyodide is 32-bit, so `np.array([100, 250, 40])` is `int32` there and `int64` on a desktop. The text says "an integer type" and quotes no dtype, so nothing changes.
