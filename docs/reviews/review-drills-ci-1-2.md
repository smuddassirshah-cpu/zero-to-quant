# Drills pack `ci`, packs 1 and 2: second-reader findings

Scope: the 30 files `app/content/drills/ci-*.json` tagged `pack-1` (hashing, prefix sums) or `pack-2` (two-pointers, windows), at commit 41e3ec0, against `docs/briefs/drills-ci-packs.md`, `docs/briefs/drills-1.8.md` and AUTHORING section 5 "Drill".
Method: I read each drill as a candidate (brief, constraints, examples), then wrote my own solution to all 30 by a method that differs from the model wherever one exists (`mine.py`). For each drill I wrote one wrong or too-slow solution the author did not plant (`wrong.py`) and ran it on every example and hidden test in CPython with a 5-second limit for the whole run. `extra_checks.py` computes each proposed new test with the model and with my solution, and shows what the wrong solution returns. I read every `notes`, `hint`, `how` and `slip` line against the model solution, and compared each drill with the other `dsa-`, `oa-` and `ci-` drills.
Scripts: `docs/reviews/drills-ci-1-2-scripts/` (from the repo root: `harness.py <mine.py or wrong.py> app/content/drills` and `extra_checks.py app/content/drills`, with the scratchpad venv Python).
Format: `N. file | JSON path | tag | what is wrong | exact fix`. Tags: `wrong` = a learner is marked wrongly or told something false; `weak` = the tests miss a real wrong solution, or the statement is ambiguous; `minor` = otherwise.

## Tool results

- Authors' scripts: `drills-ci-1-check.py` ends `errors: 0`; `drills-ci-2-check.py` ends `15 drills, 0 errors` (89 s).
- My own solutions: 30 of 30 pass every example and hidden test. No `expect` is wrong. That covers all 14 drills at difficulty 4 and 5, each by a second method (heap for the deque drills, two left edges for exact `k`, per-letter windows, counters for the pair counts).
- My unplanted wrong solutions: 19 of 30 are caught. 10 pass every test (findings 2 to 11). One more passes but is only slow on the wrong axis (finding 17).
- Caught, but only by one large pseudo-random test: `ci-trim-to-multiple` (finding 22), `ci-hop-score` (a greedy, test 13), `ci-code-classes` (test 10). A learner who fails there sees no readable case.
- `node tools/planted-check.mjs --drill <id> --require --local-cdn <pkgs>` in the foreground: `ci-others-product`, `ci-target-blocks`, `ci-capped-repeats`, `ci-ends-to-target`, `ci-paired-signals`, `ci-three-leg-nets`: each "3 planted solutions, 0 failures".
- `how` test counts match the `tests` arrays in all 30; `tags[0]` is the pack; mix 3 / 5 / 5 / 2 and two stdin drills in each pack.
- I did not run the validator, the playthrough or the voice scan (the authors report them green, and this pass only reads).
