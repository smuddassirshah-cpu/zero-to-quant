# Concept audit: mm-games, levels 1 to 3

Blind concept audit (brief: `docs/briefs/concept-audit.md`) of `app/content/courses/mm-games/` levels 1 to 3: l1 to l13, review-1 to review-3, homework-1 to homework-3. Every screen, quiz item, hint, explain, why, feedback, rubric, model answer and wrong-option line was read, and every code widget's solution was run against its examples and hidden tests in CPython. All 19 code widgets pass (219 of 219 example and hidden-test cases) and every starter fails. Claim ledger: `docs/reports/audit-mm-games-1-3-ledger.md`, 296 rows: correct 268, imprecise 22, misleading 2, wrong 2, unverified 2. Scripts: `docs/reports/mm-games-L1-concepts.py`, `-L2-`, `-L3-` (exact enumeration and Monte Carlo; all exit 0). **25 findings: wrong 2, imprecise 21, misleading 2; serious 3, minor 22.** No graded key is wrong. The three serious findings are 21 (hedge ratio read as units when the sds are percentages), 23 (realised P&L called edge) and 25 (a homework hedge traded after the risk it covers has gone).

Findings follow the pattern `N. file | JSON path | severity, tag | problem | evidence and basis | exact fix`. Every fix is paste-ready text in the course voice. Paths use `screens[n]`, `quiz[n]`, `items[n]`.

## Noted, not conceptual
