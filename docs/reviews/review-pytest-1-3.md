Scope: `app/content/courses/pytest/` l1 to l12, `review-1` to `review-3`, `homework-1` to `homework-3` (the whole course). Continuity skim of every cross-reference out of the course (first-python l10, plotting L2, the stage and topic projects) and of the courses that require pytest levels (backtest, research-int). There is no `docs/briefs/pytest.md` and no `docs/reports/pytest-<n>.md`: the course arrived in one commit before briefs and reports existed, so nothing here is checked against a brief.

Method: every graded key, every `wrong[]` value and every number in prose, hints, feedback and explanations recomputed two ways (float arithmetic as the code does it, and `Fraction`, enumeration or an independent formula) in three committed scripts. Every claim about pytest behaviour or output (collection rules, fixture calls, parametrize ids, assertion messages, `approx` and `raises` text, exit codes, the `src/` layout) checked against a real pytest run in scratch, on **pytest 8.1.1** (the wheel Pyodide 0.27.7 bundles, from the local CDN) and compared with **pytest 9.2.0**, both on CPython 3.13.18 (Pyodide runs 3.12). Every code widget run in CPython through an emulator of the code widget's harness (`app/js/engine/widgets/code.js`: one namespace, prelude, learner code, postlude, then each case's `setup` and `call`, `raises` by exception MRO), under both pytest versions.
