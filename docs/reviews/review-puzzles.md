# Topic 3.3 (puzzles): second-reader findings

Scope: every lesson, review and homework file in `app/content/courses/puzzles/` (30 lessons, 5 reviews, 5 homeworks; 194 quiz, review and homework items), read against `course.json`.
Method: every stated number recomputed independently in Python with `fractions` (scripts in the session scratchpad `read-puzzles/`): exhaustive enumeration for dice, cards, derangements, secretary orders, serial-number sets and envelope cases; exact linear solves for every pattern wait and Penney race (`penney.py`, `fsolve.py`); backward induction for the card game, reroll games, series hedges and truels; Monte Carlo (4,000,000 draws) for the broken stick, square-grid Buffon and the Kelly paths (the three l21 series were checked to share one flip sequence of 120 wins in 200). Every `wrong` value was re-derived from its `why`. Numeric keys were scanned for overlaps with their `wrong` values and for wrong values that overlap each other (`mech.py`). All 25 Python code widgets were run in CPython: each `solution` passes every hidden test and each `starter` fails (`runone.py`); simulated-test tolerances were checked against three standard errors. Choice `shuffle`, `tags`, `pace`, firm names, exclamation marks, em-dashes, American spellings, money symbols and wide display formulas were scanned mechanically. Voice: `docs/reviews/voice-scan.py` output is in `docs/reviews/voice-3.3-puzzles.txt`. Simulation figures quoted from unstated seeds (for example "a simulation of 200,000 picks gives 0.9001") were checked only for plausibility against their standard errors.
Format: `path | screen/item | severity | what is wrong | fix`. Severity: error = wrong number, false claim or wrong grading; warning = weak explanation, teaching issue or rule breach; note = style.

Counts: 2 errors, 11 warnings, 22 notes (12 of them voice-scan hits). Voice scan: 6 sentences over 20 words and 6 explanations over three sentences, 12 in all (13,365 sentences scanned). No keyed answer was found wrong, no key overlaps a `wrong` value, and every code solution passes. No exclamation marks (the hits are factorials), no em-dashes, British spelling throughout (`center` occurs only as a table `align` value), £ throughout.
